### P1-R3-F1 (HIGH) — Full-vector 6-component force convergence, near-zero component gating, off-axis $F_y$ benchmark, and honest discretization difference reporting
- **Problem:** `ForceMeshConvergenceRow` and `force_mesh_convergence_study` in `electrostatics_numerics.py` stored, compared, and gated only the $x$ components (`left_fx`, `right_fx`, `box_fx`, `net_residual_fx`). The `abs(curr) > 1e-6` filter silently skipped small/near-zero components instead of applying an absolute-error gate. `uncertainty_budget_n_per_m` computed only `|F_left,x(n_finest) - F_left,x(n_prev)|` while presenting it as a general uncertainty budget. Asymmetric regression tests checked only $x$ closure and did not evaluate a $y$-asymmetric/off-axis configuration where $F_y$ is nontrivial.
- **Required Resolution:**
  1. Carry all six conductor force components (`left_electrode_fx_n_per_m`, `left_electrode_fy_n_per_m`, `right_electrode_fx_n_per_m`, `right_electrode_fy_n_per_m`, `enclosure_reaction_fx_n_per_m`, `enclosure_reaction_fy_n_per_m`) plus full 2D net vector residual (`net_residual_fx_n_per_m`, `net_residual_fy_n_per_m`, `net_residual_magnitude_n_per_m`) through every mesh level $n$.
  2. Gate both relative changes (for active components with $|F| > \text{significant\_threshold}$) and absolute changes + magnitude bounds (for near-zero components with $|F| \le \text{significant\_threshold}$), ensuring no component is silently ignored, plus gate the 2D vector residual magnitude $\|(F_{\text{res},x}, F_{\text{res},y})\|_2$.
  3. Report per-component convergence status separately (`component_convergence`) and per-component last-refinement differences (`per_component_last_step_diff_n_per_m`, `max_component_last_step_diff_n_per_m`, and `left_fx_last_step_diff_n_per_m`) without advertising the single-component difference as a general uncertainty budget.
  4. Evaluate and regression-test a 2D off-axis / $y$-asymmetric configuration (e.g., unequal voltages and vertical electrode offsets) where all six $F_x, F_y$ components are nontrivial, asserting full 2D vector residual closure and multi-mesh convergence.
  5. Add adversarial unit tests confirming that corrupting any single $F_y$ component, near-zero component, or $y$-residual causes `is_converged_to_tolerance` to fail closed.

### P1-R3-F3 (MED) — Analytical two-material interface reflection and transmission benchmark
- **Problem:** `benchmark_two_material_interface_transmission` checked only the qualitative inequality `0 < transmitted_peak < incident_peak` without deriving the analytical reflection/transmission coefficients for the non-divergence PDE $\phi_{tt} = c(x)^2 \nabla^2 \phi$, without an incident-only reference control, without time/space separation of incident, reflected, and transmitted waves, and without refinement convergence checks.
- **Required Resolution:**
  1. Derive the exact continuity conditions ($\phi$ and $\partial_x \phi$ continuous across $x = x_{\text{int}}$) for the non-divergence scalar wave equation $\phi_{tt} = c(x)^2 \nabla^2 \phi$ at normal incidence:
     $$R_{\text{amp}} = \frac{c_2 - c_1}{c_1 + c_2}, \qquad T_{\text{amp}} = \frac{2 c_2}{c_1 + c_2} = 1 + R_{\text{amp}}, \qquad \mathcal{R}_{\text{energy}} + \mathcal{T}_{\text{energy}} = |R_{\text{amp}}|^2 + \frac{c_1}{c_2} |T_{\text{amp}}|^2 = 1$$
     For $c_1 = 1.0, c_2 = 0.6$: $R_{\text{amp}} = -0.25$ (phase-inverted reflection) and $T_{\text{amp}} = +0.75$.
  2. Run a matched homogeneous incident-only reference control ($c = c_1$ everywhere) alongside the two-material simulation ($c_1 \to c_2$), isolating the reflected wave via reference subtraction $\phi_{\text{refl}} = \phi_{\text{two}} - \phi_{\text{ref}}$ and time/space gating after complete pulse separation from the interface.
  3. Evaluate across multiple spatial/temporal refinements ($\Delta x \in (1.0, 0.5, 0.25)$), asserting quantitative agreement of measured signed $R_{\text{amp}}$, $T_{\text{amp}}$, and energy partition $\mathcal{R}_{\text{energy}} + \mathcal{T}_{\text{energy}} \approx 1$ against analytical values with monotonically decreasing error under mesh refinement.

### P1-R3-F4 (MED) — Accurate labeling of single-probe peak-squared ratio, geometric arrival gating, reference-domain return verification, and parameter sweep
- **Problem:** `benchmark_sponge_reflection_reference_subtracted` labeled `(max|phi_test - phi_ref| / max|phi_ref|)^2` as `power_reflection_coefficient` (it is a local single-probe peak-amplitude-squared proxy, not a 3D flux/energy-integrated fraction), hard-coded `pre_arrival_cutoff = 10` instead of computing arrival time geometrically from wave travel distance, and lacked a parameter/resolution sweep verifying stability and absence of reference-domain boundary returns.
- **Required Resolution:**
  1. Accurately label the single-probe metric as `probe_peak_squared_reflection_proxy` and `probe_amplitude_reflection_ratio` (preserving legacy field names only as documented aliases), and also compute the **3D volume-integrated reflected energy fraction** `integrated_reflected_energy_fraction` ($E_{\text{refl, interior}} / E_{\text{initial}}$) of the reference-subtracted difference field $\delta \phi = \phi_{\text{test}} - \phi_{\text{ref}}$ in the interior domain.
  2. Compute `geometric_pre_arrival_step` and `reference_wall_return_step` directly from the wave speed $c_0$, time step $\Delta t$, pulse radius, sponge entrance distance, probe offset, and reference box size; verify `reference_wall_return_step > n_steps` and confirm numerically against an enlarged reference domain (`ref_grid_size=110` vs `90`) that reference-domain wall return is zero to machine precision ($< 10^{-10}$).
  3. Implement `benchmark_sponge_reflection_parameter_sweep` sweeping grid size, $\Delta t$ Courant factor, sponge thickness $w_{\text{sponge}} \in (6, 8, 10)$, and reference domain size $N_{\text{ref}} \in (90, 110)$, regression-testing sweep stability and monotonic absorption improvement with sponge thickness.

### P1-R3-F5 (MED) — Actual terminal sampled continuum energy vs maximum trajectory drift
- **Problem:** `benchmark_two_material_energy_conservation` returned `final_energy = h_cont_0 * (1.0 + max_cont_drift)`, fabricating the final energy from the unsigned maximum relative deviation over the trajectory rather than returning the actual terminal sampled energy at the final step.
- **Required Resolution:**
  1. Record the full sampled continuum energy trajectory and exact discrete Hamiltonian trajectory; return the true terminal sample `cont_trajectory[-1]` as `final_energy`, alongside `terminal_continuum_signed_drift_ratio = (final_energy - initial_energy) / initial_energy` and `max_continuum_diagnostic_drift_ratio`.
  2. Add adversarial regression tests verifying that `final_energy` equals the terminal sampled energy `compute_sampled_continuum_energy_diagnostic(phi_final, phi_prev_final, ...)` to machine precision, including a case where the signed terminal change is negative (`final_energy < initial_energy`), which strictly falsifies `h_cont_0 * (1.0 + max_cont_drift)`.
